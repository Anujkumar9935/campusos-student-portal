# CampusOS Student Portal

CampusOS is a single-page student portal prototype for a college project. It brings a student's timetable, attendance, assignments, campus announcements, study planning, and expense tracking into one dashboard.

## Features

- Dashboard with today's schedule, attendance overview, assignments, and monthly expenses
- Weekly timetable for Monday to Friday
- Subject-wise attendance summary plus a calculator for attendance targets and safe absences
- Study planner with date, subject, priority, completion tracking, and deletion
- Assignment search, pending/completed filters, due-date labels, completion, deletion, and adding assignments
- Searchable and filterable campus notices
- Expense tracker with categories, monthly budget progress, and local browser storage
- Responsive layout for desktop and mobile

## Run it

Open the live site at https://anujkumar9935.github.io/campusos-student-portal/ or download/clone this repository and open `index.html` in a modern browser. No build step or package installation is required.

Some college, student, and schedule data is fictional demo content. Assignments, study plans, and expenses are stored in the current browser's local storage; they do not sync between devices.

## Customize

Open `index.html` in a text editor and edit the timetable, attendance, notices, profile, and sample tasks in the JavaScript near the bottom of the file. Replace the sample data before using the project as a real college portal.
