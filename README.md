# CampusOS Student Portal

CampusOS is a single-page student portal prototype for a college project. It brings a student's timetable, attendance, assignments, campus announcements, and expense tracking into one dashboard.

## Features

- Dashboard with today's schedule, attendance overview, upcoming assignments, and monthly expenses
- Weekly timetable for Monday to Friday
- Subject-wise attendance summary
- Assignment search, pending/completed filters, due-date labels, completion, deletion, and adding assignments
- Searchable and filterable campus notices
- Expense tracker with categories, monthly budget progress, and local browser storage
- Responsive layout for desktop and mobile

## Run it

No build step or package installation is required. Download or clone the repository and open `index.html` in a modern browser.

Some demo data is fictional. Expenses and assignments are stored in that browser's local storage and do not sync between devices.

## Customize

Open `index.html` in a text editor and edit the timetable, attendance, notices, and profile details in the JavaScript near the bottom of the file. Replace the sample campus data before presenting this project as a real college portal.
